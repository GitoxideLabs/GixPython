# Security policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/GitoxideLabs/pygix/security/advisories/new) for GixPython when it is enabled. You can also contact Sebastian Thiel at `sebastian.thiel@icloud.com`.

Include the affected version, Python version and platform, build features, impact, and a minimal reproduction. Please avoid public disclosure of sensitive details while a fix is being coordinated.

For a vulnerability in the native engine, Gitoxide's [security policy](https://github.com/GitoxideLabs/gitoxide/blob/main/SECURITY.md) describes its reporting process.

## Supported versions

GixPython is under initial development. There is no published stable release or long-term support series announced by this repository. Security fixes are developed against the current source until a release support policy is established.
